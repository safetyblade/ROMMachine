Offline interaction study of the owner's second sketch. Not an Android gamepad or an ergonomics test. Drag each D-pad, action or shoulder button independently; compare upper shoulders with shoulders near A/B. Nothing here changes emulator inputs.

PivotArc design controls
Shoulders:

Control topology and available space

Drag any button to adjust its position. Select Move whole cluster to drag every button together. All dimensions are schematic dp proxies, not live PadKit input bounds. Start/Select/Menu remain in a separate future utility zone.

Adjust Position & export

Select a button by touching it. The arrows move either that button or the complete cluster by 8 units. The HTML stores custom positions locally when supported.

Contact ownership

Pointer-down activates only that button. Moving the same pointer across another circle does not activate it; release clears ownership.
