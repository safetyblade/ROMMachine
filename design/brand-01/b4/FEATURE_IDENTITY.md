# BRAND-01 / B4 — Signature features and shared icon library

Design candidate on the same B1–B3 branch, 18 November 2026. B3 visual approval is recorded. Owner decision: no promotional taglines throughout the product family. Parent product marks and Junior remain unchanged. No app source, engine, save, schema or build changes.

## Hierarchy
- Signature technologies: *PivotArc* and *GripArc*. Use true semibold italic for live text, including accessibility and Settings labels. Standalone custom path-drawn italic display/engraving wordmarks use approved casing; no skew applied to the CARTDECK logo. Use the small accompanying icon only when helpful; no mandatory mark beside every occurrence, no new logo in gameplay chrome. Engrave only outside input/render areas and respect existing geometry.
- Nested products: **Modern** (within Settings > Controllers, contextual entry from Game Controls) and **Vault** (within SafeSave). Owner-approved public names and product hierarchy; each has its own candidate symbol, wordmark and lockup, with dedicated child routes and no adult dock item. Internal identifiers may remain unchanged; no migration or functional claim. Modern requires verified game support; Vault is future only until secure backend, account linkage, explicit opt-in and restore are verified.
- Named capabilities: GEMRating, GemFinder and DeckFit. Upright B1 type and supporting icon, no independent navigation. Separate actual user ratings, recommendation and fit signals.
- Functional names: Patch Studio, My Sources, My Appearances, PC Game Setup, Help & guides, FAQs, Grown-Ups, Controllers and other actions. B1 typography plus one shared icon, not individual wordmarks. Settings owns controls and appearance, GEM owns website search and My Sources, CARTMOD owns preparation and FAQs, Shelf owns cover search; SafeSave owns saves.
- B2/B3 product marks are reused exactly. No new team personae or mascot. No tagline anywhere.

## Hardware protection
PivotArc and GripArc marks describe a feature, not the actual controls. Existing PivotArc approved v2 source, safe-fit solver, tap regions, hold feedback and game viewport stay untouched. Existing GripArc full L shell, fixed G1–G4 positions and active count are invariant. Brand decoration is pointer-transparent. No inactive ghost controls, new mapping, extra key chord or status illumination. If insufficient space, omit decorative marking rather than reduce targets or art. Real italic font availability and engraved physical proof remain implementation checks. Custom drawn path labels are candidates for visual review, not font files.

## Icon grammar
24-unit viewBox, 1.75 stroke, rounded caps/joins, simple familiar silhouettes; use 24dp normally/20dp compact/16dp metadata only, actionable touch target >=48dp. Use semantic foreground from active appearance (incl. Light), optional contrast-safe accent for selected state; ensure >=3:1 adjacent contrast, normal labels >=4.5:1. Geometry consistent across themes. Favourites have outlined and filled approved state candidates; selection semantics and label must reflect real state. No use of brand symbols as success or backup status. Use shared Confirmed/Warning/Protected for meaning and accompanying readable text. All icon-only actions need accessible label; decorative paired icons do not duplicate announcement. For RTL mirror only directional navigation where appropriate, not feature marks or gamepad glyph. Controller/TV shows visible focus outline and state; no touch-only actions. Disabled state communicates unavailable action, not unsupported placeholder; no essential indicator solely by color. Actual card/button, loading/empty, focus and error components follow in B5.

## Assets and integration
feature-icons.json enumerates feature marks, two original italic path wordmarks and shared SVGs with stable IDs. Existing product and Junior SVGs referenced, not recreated. Each SVG has currentColor, title/accessible metadata, no remote assets, fonts or script. Specimen is static, not app screenshot. Conversion to Android paths must preserve geometry and semantics and be checked at 20/24/32dp and 2x scale. B1 typeface packaging remains pending owner/license review. All runtime integration deferred until B5/B6, actual support verified, current master baseline and full APK gates. Asset structural review is not independent legal/trademark, device presentation or runtime verification.
