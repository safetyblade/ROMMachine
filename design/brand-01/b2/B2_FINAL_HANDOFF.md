## D. GEM Search and My Sources
Fourth GEM section Search, independent of local Browse query. Landing: text field "Search for a game, mod or guide"; optional platform/filter input; select one enabled source row, group by user-maintained category; "Search website" opens only that selected website through platform-supported external browser. My Sources: add, edit, delete, enable/disable, reorder, create/rename categories or reassign; no example websites preloaded unless separately approved. Local offline source register; first run shows "Add your first website". Search can offer a source that only has a home URL as "Open website" (no false integrated search). Each editable record: stable UUID, display name, HTTPS home URL, category, optional HTTPS search template with exactly one {query} in a query parameter value, enabled flag and order; optional system label for organization (not compatibility proof). User enters URL from their chosen website, optional template; preview resolved URL with sample query; Test search opens browser only on explicit action; Save validates, Cancel changes nothing. Restrict template to same exact canonical HTTPS host/port as saved home URL, no credentials, fragments, control chars, IP/private/local hosts or unsupported protocols; no placeholders in host/path/port/key; encode a single UTF-8 query parameter value, not raw concatenation, never execute script. Reject invalid/duplicate names or same normalized home+template duplicates with user correction; don't merge other records. Do not auto-scrape, batch query sites, import cookies, query arbitrary pages in background, proxy data, store passwords or call an unreviewed API. Show external destination hostname before launch; user may decide not to send their query. No ROM upload, local path, saves, identity, telemetry or sensitive input included in query; explicitly discourage secrets. External navigation not proof of availability, legality or compatibility. No automatic downloading, ROM installation or sideload. No promises of results embedded in GEM; external browser only for MVP. Browser unavailable/offline/invalid source: show clear error, allow editing and preserve query. Return retains search term/source and focus; persisted sources survive restart if repository ready. Query session-only by default; profile-specific access when profile authorization delivered. Junior cannot enter adult web search even via deep link. No new global unfiltered entry. Existing SourceDraft/SourceEditor is unmounted callback design; move its ownership/copy to GEM and extend fields only after versioned persistence/authority design. Do not create second register in CARTMOD. Capability adapter must verify actual storage; hide Search if feature not implemented, not whole GEM if other actual sections available.

## E. Shelf cover search
From any authorized cartridge in Shelf: hold/long-press or controller equivalent contextual action -> "Search for covers" directly (not only buried in setup); preserve existing contextual controls and artwork actions. Context captures canonical immutable cartridge ID and display identity, not list index or filename hash. If current popup only exposes details, add direct action to same artwork editor; existing Cartridge Setup > Cartridge artwork remains a shortcut to the same flow. Screen title "Search for covers": current cover/fallback, game title and console, editable query preset from actual title + console label + "game box art"; optional if provider supports it, no invented variant metadata. "Search covers" uses existing user-initiated Google Images browser pathway with encoded query; provider name visible; MVP external results do not auto-import. Search only the selected title (not whole library or source file path). User finds an authorized image, returns, chooses "Upload / replace image" via existing local picker, preview selected image and explicitly confirm "Use cover" (reuse current CustomCoverManager and actual callbacks; add preview before existing write); Cancel keeps prior image, invalid/corrupt/oversized input shows reason and retains prior art. Reset only available if custom cover exists; explicit reset to default art, never delete ROM/save. Preview preserves art aspect/crop policy and front/spine fallbacks; carry selection across rotation/browser activity result, revalidate canonical ID and current profile authorization before write; if cartridge removed/changed, stop, do not target replacement. On back return same Shelf section, scroll/focus and saved arrangement, no rescan just for changing cover. TV/controller open contextual action and browser/file picker only if reachable (provide existing local upload alternative; no dead action). Junior cannot use unrestricted web search or edit shared cover; manager-authorized path only when implemented. No scraping, download automation, copyrighted artwork bundled or app claiming rights. Existing custom cover manager bounds and atomic update verified; no parallel cover store or save writes.
