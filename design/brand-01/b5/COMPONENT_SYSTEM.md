# BRAND-01 / B5 — Shared component and interface design

**18 November 2026 · Design candidate on existing B1–B4 branch.** User-approved Modern and Vault nested-product hierarchy; public labels are Modern and Vault only. No taglines. B5 defines reusable presentation and interaction contracts for B6, not a new architecture or source implementation. B1/2/3/4 and JR01 remain controlling for product behavior. Current actual master and recovery state must be re-audited at implementation.

## 1. Foundation
Use B1 Source Sans 3 candidate (system sans fallback until font licensing/packaging approved), true italic PivotArc/GripArc, B2/B3/B4 SVGs and shared role tokens; no edgy retro style. All text live except approved vector wordmarks; accessibility name canonical, no repeated screen-reader name. Use a quiet room/surface/raised composition, 12dp card/8dp control radius, 4dp spacing grid; 16dp ordinary inset, 8dp compact. 1dp low-noise dividers, no giant product banners, gradients/neon/texture behind text. 24dp icons, 20dp compact, 16dp metadata, min 48dp hit targets (Junior primary 56dp). All component dimensions are minimums, never fixed text boxes. One primary action per decision group; secondary actions outline/text. Status must be readable, never implied by brand tint. Text >=4.5:1, focus/essential boundaries >=3:1; use contrast-safe semantic fallback for custom palettes. B1 decorative outline token is not adequate for every essential boundary; test actual adjacent role, promote to higher-contrast outline or ink as required. Light is selectable, Original default. All logos react to the active appearance; no forced brand colors in user finishes. Do not mutate appearance or layout stores when applying component styles.

## 2. Component library and interaction states
- Product header: mark + name once, optional actual scope in subordinate text only; Back and contextual actions. Use full lockup where it fits, mark plus live name otherwise. No tagline or empty chrome rows. Parent root dock remains shared; nested routes show Back, never new top-level tab.
- Product dock: Shelf, GEM, SafeSave, CARTMOD, Settings in order, capability-gated. Selected uses actual route, visible shape/indicator and accessible selected label; focus is independent of selected; pressed follows actual input. Keep prior shelf section/scroll/filter and stable route IDs; preserve current hidden routes until migration parity; edit mode replaces dock with Done/Tools/Undo. No decorative spacer permanently consumes viewport. 
- Action card: concise label, one factual purpose or live status, optional icon and trailing chevron. Entire actionable row OR a separate explicit action (not duplicate nested event handlers). Longer workflows present review screen not wall of text. Group secondary actions and expandable detailed help. 
- Menu row: shared measured min 48dp, standard icon/label/right control, subtle divider. Same row size and density across universal game main/submenus; label wraps and grows under accessibility font scaling. Back/Resume/Return to Shelf remain reachable. Existing game-specific capabilities and actual actions unchanged, advanced diagnostics remain within Advanced. No extra app dock inside gameplay. Respect current input ownership, runtime pause/resume and safe return, no new global controller shortcut. Junior menu uses approved limited actions.
- Buttons: primary filled, secondary outline, tertiary text, destructive explicitly labelled/confirmed. Minimum target applies even icon-only. Visible high-contrast focus ring and separate pressed state; selected semantics not only color. Busy blocks duplicate commits but retains meaningful supported cancel/back; error shows remedy; success only on actual verified completion.
- Settings: clear current value and scope (global defaults vs This game), appropriate switch/selector or mapped action. Preserve existing immediate-write versus draft Save/Cancel. Mapping capture modal owns input; test only actual observed signals, preserve conflict/unsaved protection. No decorative fake controller inputs. Appearance card reuses actual editor/preview; draft changes do not silently commit.
- Sheets/dialogs: title, target game/player/device, impact, explicit choice, Cancel; destructive action never initial focus/default. Support scroll, large text and controller. Sheet dismissal or browser/picker cancel keeps data and returns focus. Navigation changes do not interrupt service work. 
- Feedback: loading/empty/no matches/unavailable/error/verified, labels not colors alone. Distinguish setup needed, detected not verified, excluded, active/locked, actual verified result and unknown. Do not claim readiness after import, completion before save verification, or successful remapping before actual commit. Diagnostics not player-facing unless requested.

## 4. Modern and Vault — nested-product workspaces
Modern owns a capability-gated entry in Settings > Controllers, and a game-scoped shortcut in existing Game Controls when actual support proven. Header mark and Modern wordmark; supported games/available configurations if real service exposes them, selected game + controller profile scope, current active configuration and available actions; review/test/enable or restore previous behavior via approved control implementation only. No unsupported game options, no fake compatibility, no assumed patch/app install. If service not available leave route unmounted; in a supported context explain unavailable config result, preserve current mapping. Exact features, resolver and persistence governed by GC/PERF planning; no schema or new mode authority. 
Vault owns nested SafeSave route. Own mark and Vault wordmark. First verified entry explains account connection and permitted save scope, explicit opt-in, no ROM/BIOS/firmware. Actual authenticated state, profiles, snapshot inventory, manual upload/download with verification and conflicts, storage/retention, disconnect; no automatic/background sync in first authorized stage. Existing legacy Drive sync remains distinct. No saved/synced badge before verification. Never expose Connect or Upload placeholders before secure backend authorization, client confidentiality/key recovery, tested server authorization and verified restore. No independent bar tab. Internal Modern Function/SafeSave Vault identifiers remain until architecture explicitly migrates; public copy only Modern / Vault.

## 5. Responsive
Measure actual content constraints, safe insets, font scaling, not physical orientation alone. Portrait preserve five physical spine slots at approved normal width; front footprint 3. Short landscape uses compact 48dp-min dock and header and horizontally grouped actions that scroll with content, minimum 48dp targets, no permanently stacked search/section headings. If labels exceed width use reachable scrolling dock or stacked compact option with focus/autoscroll, not tiny text or hidden destinations. Tablet/DeX optional two-column task cards and details where width allows, preserve independent section scroll. TV safe area and scaled labels; explicit focus traversal, focus restore on overlays and selection, no hover/touch-dependent action; existing GC routing only. At 2x font scale allow wrapping and vertical scroll, do not hide existing primary actions. Theme previews never crop real game art or change emulator viewport. Junior retains one cover.
