# PivotArc multi-button design study — #377

Status: owner-directed research, not approved new geometry or implementation. Standard PCE approved; reject previous six-button rows/6 Holds. One-handed thumb path first, not original controller spacing.

Compare Mega Drive/Sega CD A/B/C and XYZ variants, SNES ABXY + L/R, PSP four-face radial reference (visual frozen, placement/Hold review open), PC Engine I–VI and Avenue Pad 3 alias, later PSX/NDS/3DS, Saturn only if added to system roster (not in current 33). Shared topology does not imply shared native key identities.

Game evidence: Sonic A/B/C jump (https://manuals.plus/m/a590dd5a053f8b853cf983ebe28dc2c4eaa26309e1539077abe6b9aa2e8047ac); Streets of Rage 2 A special/B attack/C jump, B+C combo (https://gamefaqs.gamespot.com/genesis/563344-streets-of-rage-2/faqs/2862); Super Mario World Y/X run, B jump, A spin (https://www.world-of-nintendo.com/manuals/super_nes/super_mario_world.shtml); PC Engine Avenue Pad 3 III alias Run/Select (https://docs.joypad.ai/protocols/PCENGINE/); PCE 6 button core support upstream only (https://docs.libretro.com/library/beetle_pce_fast/).

Proposed research order: review exact PSP accepted source/screenshot for radial spacing and neutral thumb path; three-button near-thumb arc as a separate profile (B central action, C nearest lower action, A outer/upper less frequent in SoR2; not yet geometry); four-button near-thumb fan around movement nucleus; six-button two-tier fan with actual face inputs and selected Hold, not double rows of Hold switches. Evaluate game-specific sustained input (run/fire) vs discrete/timing-sensitive action (jump/special/punch/kick); configurable Hold assignments are proposals, not universal defaults. Existing two-button Hold pairs locked. Retain complete guest controls and safe 48dp+ targets, no overlap and no false claim of simultaneous single-thumb gameplay. Validate thumb approach/sweep, travel, accidental activation, combinations, mirror and physical fit; disclose inability to fit rather than shrink hitboxes, remove keys or invent macros. No build until owner design approval. Exact PSP geometry and current-head bindings not yet audited.
