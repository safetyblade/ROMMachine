# GripARC shared visual reference
This is a reconstruction of the common visual language used in the approved chat schematics, not a new artwork approval or a measured Compose render. Each system packet governs exact relative seats, counts, legends, variants and orientations. GBA is the visual foundation, not a universal geometry template.
- Full manufactured shell, dark machined purple/black base (#302938 to #1c1723), chamfered edges, layered inset rims (#68566f), subtle pink accents (#bf508f / #bd538f). Preserve current appearance/edition color system; these are illustrative signature palette values, not hardcoded replacements for user themes.
- Native cap: recessed dark well, nested collar, raised contrasting cap, white readable native legend. Programmable cap: distinct smaller collar/pink accent and two-line functional legend, no visible G1-G4. Hold active cap depressed and illuminated; Turbo clear while active. Native directional pad distinct from analogue well and digital arcade ball-top; no fake axes.
- Native-inspired color accents only where approved (N64 C cluster gold, GameCube A/B and C-stick, Xbox face color, Atari fire red, Wii IR blue). Maintain detailed chassis even around compact controllers; vents and unused pockets are decoration, never touch targets. No pasted generic button overlay, no featureless rectangular panel.
- Portrait reference chassis 360-wide, variable height per packet; outline M26 5 H334 L353 25 V[h-27] L332 [h-5] H28 L7 [h-27] V25Z. Preserve actual existing CARTDECK surround and game display above; reference units not dp. Use packet topology and measured fit.
- Landscape reference original asset `design/cartdeck-v04/shell/chassis-landscape.svg` (730×390) and actual GameScreenLayout safe viewport. CARTDECK logo above screen; smaller GripArc wordmark on hardware. Do not rotate portrait, overlay image, crop gameplay or force all systems to same aspect. Reconcile 180dp reference side decks with actual measured sizes and >=48dp independent touch regions. Do not shrink hit areas below minimum.
- Render from exact packet centres, including inherited variants; use independent hit bounds and responsive spacing while keeping relative placement. If source/fit conflict cannot be resolved without materially changing intent, report the exception with evidence rather than silently omit or distort controls. The user will review the consolidated APK, not a new series of design approvals.
