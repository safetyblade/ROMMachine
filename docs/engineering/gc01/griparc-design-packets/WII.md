## C — Remote + Nunchuk — GA-D31C-R2 Aim & Fire (supersedes initial C layout)

Retain all native keys, existing mode IDs touch=2/stick=1/relative=0 and coordinate mapping. 
### New interaction contract
Aim & Fire is an explicit opt-in host-side pointer action, not a fifth Wii guest device or another guest axis. Default Aim Only: pointer gesture sends IR only. Fourth programmable seat Aim & Fire arms/disarms coupling of pointer contact and one verified guest digital button (default B, reassignable to actual game fire binding such as A). Clearly indicate armed state and selected guest key. While armed, fresh pointer contact establishes actual aim and then dispatches guest fire DOWN; maintain fire through pointer motion and independent left movement; fire UP on release/cancel while left movement continues. Repeated distinct pointer contacts permit individual shots (no forced repeat, no auto-turbo, no automatic re-fire on continued drag); Hold B remains separately available for sustained fire; optional Turbo only through explicitly selected verified action, never default. Independent native B remains reachable for manual fire, including extra-finger input. For games requiring unbroken aiming while manually pulsing fire, independent fire with a third finger or opt-in repeat are alternatives; two-thumb continuous aim plus arbitrarily timed individual fire while both contacts remain down is not guaranteed by contact coupling. Preserve existing pointer neutral/offscreen semantics, no invented coordinate or stick-click action, never force pointer to centre just to send fire. In touchscreen mode apply same explicit coupling only to valid gameplay viewport pointer contacts, not controls/letterbox; aim position first, then fire through actual guest dispatch. Stick mode couples to actual IR stick gesture, not camera or fake analogue. Mode/target change, pause, menu, focus loss, rotation, cancellation, game exit or relevant disconnect release coupling-owned guest fire and pointer/movement as appropriate; independent per-source ownership, never release another active source; no rearm/re-fire on resume or existing contact. Store preference/assignment, not live armed state. No silent enabling, no pressure detection or gesture inference. Existing standalone Hold A/B/Z still available. Actual IR regression must be fixed in native dispatch; new coupling must not mask it.
